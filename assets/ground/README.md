# Reference ground data

These maps are generated by executing `references/src/world/ground/geometry.js`,
using the reference's high texture quality (1024px mask, 512px detail/normal data,
2048px markings). Run `node scripts/export-ground.cjs` from the repository root to
regenerate them. This uses the existing Playwright installation and the local
Big Shoulders Display font; its license is in `references/licenses/`.

All four maps contain **linear data**, including their alpha channels. Mask R is
puddle elevation, G dampness, B oil, A traffic wear. Markings R is yellow paint,
G white paint, B tyre rubber. Detail and normal RGBA channels are packed exactly
as in the reference. Rows run toward increasing world Z. The manifest records
source and output hashes. The exporter writes data PNGs without canvas alpha
premultiplication, and the runtime generates full linear mip chains.

The shader port is `crates/models/src/materials/wet.wesl`. It retains the reference
surface layers, derivative filtering, rain rings, wave spectra, foam and scum.
The CPU sea mesh uses the reference's adaptive grid and gravity-driven swell,
including horizontal displacement and the far-water skirt. Surface queries use
the same mask with the reference's warehouse exclusion.

Native medium/high rendering adds a half-resolution HDR planar reflection with
an oblique ground clip plane. Wet surfaces and rain are excluded from that view.
Bevy's forward PBR lighting is used for these two surfaces, with the reflected
scene composed using Fresnel weighting. Its small roughness-dependent blur kernel
replaces the reference's reflection mip sampling; the lighting result is not
pixel-identical to Three.js. WebGL uses the same ground/water shader and rain
splashes with Bevy lighting, without the extra planar camera. Low/simple quality
retains the existing standard-material fallback.
